# 02 交付说明

## 安装

- 环境：Stardew Valley 1.6（Steam 版）、SMAPI 4.x。
- 把 `SocialPageOrderButton` 整个文件夹放进游戏的 `Mods` 目录（当前已就位）。
- Generic Mod Config Menu（GMCM）为可选：装了可在游戏内“选项 → Mod 选项”里改排序；没装不影响使用。

## 使用

1. 按 `E` 打开菜单，切到“社交”标签。
2. 点标签条最左侧的“排序”按钮（空间不足时显示为三横线图标），展开三个排序项：好感、名字（拼音）、生日。
3. 每一项右侧有方向箭头：**点名称**按该方式的默认方向排序（好感降序、名字升序、生日升序）；**点箭头**翻转方向。点击后立即生效并写入 `config.json`。
4. 当前使用的排序项有左侧深色竖条 + 浅黄底色标记。
5. 点击面板以外的区域关闭面板，不改变当前排序。

## 配置项（config.json）

| 字段 | 取值 | 默认 | 含义 |
|---|---|---|---|
| `SortMode` | `Friendship` / `Name` / `Birthday` | `Friendship` | 当前排序方式 |
| `FriendshipDescending` | `true` / `false` | `true` | 好感排序方向 |
| `NameDescending` | `true` / `false` | `false` | 名字排序方向 |
| `BirthdayDescending` | `true` / `false` | `false` | 生日排序方向 |

首次启动、`config.json` 缺失或读取失败（损坏、字段非法）时一律回退“好感降序”，三种方向取默认值，并写 warning 日志，不阻断启动。

## 已知行为

- **名字排序分两段**：以汉字开头的名字为汉字段，按 zh-CN 拼音；其余名字（英文、数字等）为非汉字段，按字母序。非汉字段整体排在汉字段之后——**英文名永远沉底**，升降序只翻转段内顺序。比较忽略大小写、全半角与变音符号；显示名相同（含仅大小写差异）时按 `InternalName` 兜底，多次打开顺序一致。
- **好感排序与原版顺序不同**：原版按好感点数降序 → 见面顺序 → 显示名，且未见面角色与孩子在末尾；本 mod 按心等级 → 精确点数（方向一致）→ 名字规则，未见面角色固定排在有数据条目之后。两者主键相同，但同分时的先后会不一样。
- **不实时重排**：菜单里送礼改变好感时列表不会当场跳动；关闭菜单或切换标签后重新进入社交页即按新数据排序。
- **生日**：按“距离下一个生日的天数”排，当天为 0 天；无生日数据的条目排在末尾并保持相对顺序。
- **数据缺失**：无好感数据的条目排在有数据条目之后；未见面角色在所有排序下都排在已见面角色之后。
- **按钮位置**：固定在标签条最左侧空白格，避开 UI Info Suite 2 等 mod 在右上角自绘的按钮；不遮挡标签、关闭键、滚动条与列表内容。
- **操作方式**：目前为鼠标点击，不支持手柄/键盘导航到该按钮。

## 兼容与卸载

- 与 UI Info Suite 2、LookupAnything、Ridgeside Village 同开无报错（Ridgeside 对社交页行绘制的补丁与本 mod 不冲突）。
- 卸载：删除 `SocialPageOrderButton` 文件夹即可；mod 不修改存档。
